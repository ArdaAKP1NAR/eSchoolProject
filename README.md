Modern, hızlı ve ölçeklenebilir bir okul yönetim sistemi.
Öğretmen, öğrenci, sınıf, ders ve not yönetimlerini tek bir panelden kontrol etmeyi sağlar.

🚀 Özellikler
🏫 Okul Yönetimi

Okula bağlı sınıfların yönetimi

Sınıf listesi, öğrenci sayısı görüntüleme

Sınıfa öğrenci ekleme/çıkarma

👨‍🏫 Öğretmen Yönetimi

Öğretmen ekleme/güncelleme

Öğretmenin verdiği derslerin görüntülenmesi

Sınıf–öğretmen eşleştirme

📘 Ders Yönetimi

Ders ekleme/güncelleme/silme

Derse bağlı sınıf ve öğretmen seçimi

Ders güncellenince programın otomatik etkilenmesi

🕒 Ders Programı (Lesson Schedule)

Sınıfa göre ders programı getirir

Öğretmene göre ders programı filtreleme

Gün–saat bazlı düzenlenmiş listeleme

Öğretmen değiştiğinde otomatik güncellenmiş program desteği

🧑‍🎓 Öğrenci Yönetimi

Sınıfa bağlı öğrencileri görüntüleme

Öğretmenin ders verdiği sınıfa göre öğrenci listeleme

Öğrenciye not ekleme

📝 Not Yönetimi

Exam type (Sınav türü): Vize, Final, Performans vb.

Öğrencinin notunu kaydetme/güncelleme

Transaction destekli güvenli kayıt işlemi
(Her not işlemi tek seferde ya kaydedilir ya da geri alınır)
